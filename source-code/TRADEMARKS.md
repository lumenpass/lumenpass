# LumenPass Name and Branding

The Mozilla Public License 2.0 licenses covered source code. It does not grant permission to use contributor trademarks, service marks, logos, signing identities, or store listings except as necessary to describe the origin of the software and comply with license notices.

## Forks and modified distributions

You may accurately state that a project is based on or derived from LumenPass. Unless you have separate written permission, a modified distribution should:

- use a distinct application name, package identifier, bundle identifier, and store listing;
- replace LumenPass logos and other brand assets that could imply an official release;
- use its own signing certificates, OAuth applications, API credentials, domains, and support contacts;
- clearly state that it is an independent fork and is not endorsed or supported by the LumenPass maintainers;
- preserve copyright and license notices required by MPL-2.0 and applicable third-party licenses.

Unmodified redistribution may identify the software as LumenPass, but must not imply that the distributor is the official publisher or support provider.

## Descriptive use

Fair, truthful references such as “compatible with LumenPass” or “derived from LumenPass” are permitted to the extent allowed by applicable law, provided they do not create confusion about origin, sponsorship, or endorsement.

For permission to use official branding beyond descriptive use, contact **staff@lumenpass.app**.
